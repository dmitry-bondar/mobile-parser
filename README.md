# Mobile parser

Android UI-экстракторы на TypeScript: скриншоты, выбор магазина и сбор товаров через ADB без доступа к внутреннему API приложения. Сейчас реализована «ПОБЕДА честных цен». Поддерживаемая среда — Windows x64, Node.js 22, JDK 17 и локальный Android SDK.

- [Разработка и диагностика](docs/DEVELOPMENT.md) — структура, данные, логи, новые экстракторы и проверки.

SDK и AVD не входят в Git. На новом компьютере сначала выполните установку по инструкции. Все команды запускайте из корня проекта. Скриншоты поддерживают подключённое устройство, но сценарий Победы рассчитан на конкретный AVD.

## Запуск

```powershell
npm ci
npm run check
npm test
npm run android
npm run devices
npm run screenshot -- home
```

Скриншоты сохраняются в `screenshots/`.

`npm run android` запускает только Android и ждёт готовности системы. Если нужный эмулятор уже запущен, используется он же. Приложение и экстрактор не запускаются; эмулятор остаётся открытым для ручной работы.

Для Play Store-эмулятора включена клавиатура ПК (`hw.keyboard=yes`) и общий буфер обмена Windows/Android. Нажмите на поле ввода и печатайте с ПК; для вставки используйте `Ctrl+V` или удержание поля → «Вставить». Если включён рукописный режим Gboard, экстрактор отключает его при запуске и сохраняет показ экранной клавиатуры. Изменение `hw.keyboard` применяется после перезапуска эмулятора.

## ПОБЕДА честных цен

По умолчанию используется AVD `mobile-parser-playstore-api35-recovery` с Play Store. Он создан после повреждения файловой системы прежнего AVD; старый `mobile-parser-playstore-api35` сохранён без изменений. Для другого AVD задайте `$env:ANDROID_AVD = 'имя-avd'`. Одна команда запускает его, если он выключен, ждёт полной загрузки и открывает приложение:

```powershell
npm run pobeda
```

Приложение должно быть установлено заранее. Идентификатор: `ru.tkleto.app.magazinpobeda`.

Экстрактор находится в `src/extractors/pobeda/`; адрес и пути категорий задаются в `config.json`. Общие операции Android находятся в `src/android.ts`. Новые приложения могут иметь свои папки экстракторов и отдельные npm-команды.

Конфиг — массив объектов, которые обрабатываются последовательно:

```json
[
  {
    "address": "Университетская 109",
    "categories": ["Алкогольные напитки/Водка"]
  },
  {
    "address": "Косточкина,6А",
    "categories": ["Мясо/Мясо птицы"]
  }
]
```

Общий `products.json` обновляется после каждого магазина. Скриншоты разделены по папкам `store-1`, `store-2` и далее. Товары разных адресов не перезаписывают друг друга. Ошибка категории записывается в лог, накопленные товары сохраняются в `products.partial.json`, обход продолжается со следующей подкатегории. Если возврат к родителю не удался, обрабатывается следующая категория конфига с возвратом к корню каталога. Ошибки запуска, авторизации и выбора магазина останавливают сбор. Эмулятор выключается в конце всей работы. Сбор с ошибками завершается с кодом 1, даже если остальные категории собраны.

Адрес не обязан совпадать с написанием в приложении: `Молодежная,2А` и `ул. Молодёжная, д. 2 А` сопоставляются. Номер дома, буква, корпус и строение проверяются точно; 8 не совпадёт с 80 или 8А. Для исключения одноимённых улиц укажите город, например `г. Самара, ул. Молодежная, д. 2А`. Правила и ограничения описаны в документации разработки.

Экстрактор ждёт загрузки приложения, проверяет слова входа/авторизации и при необходимости пишет ошибку и выключает эмулятор. Затем проверяет адрес на главной по правилам нормализации: если он соответствует конфигу, сразу открывает каталог, без поиска магазина и переключения клавиатуры. Если адрес отсутствует или отличается, выбирает магазин и подтверждает адрес на главной. Если у категории есть дочерние, рекурсивно обходит их все и собирает товары в конечных категориях с прокруткой до конца списка. В результатах сохраняется полный путь категории.

В `outputs/pobeda/<время>/` сохраняются `products.json` (название, цена в рублях, наличие, категория и адрес) и PNG каждой страницы в папках магазинов. У отсутствующих товаров цена может быть `null`. При ошибке сохраняется `products.partial.json`, команда завершается с ненулевым кодом. Дубликаты внутри категории одного магазина удаляются по названию: UI списка не предоставляет идентификаторов товара.

В этой же папке находится `run.log`: сообщения дублируются в консоль, содержат UTC-время, уровень, этапы обработки, прогресс страниц и ошибки со стеком. Отдельный `npm run android` пишет в `logs/android-<время>.log`. Это логи программы, не Android logcat. Ротации нет; результаты, логи и скриншоты не коммитятся и могут содержать персональные данные.

Для кириллического ввода используется `adb-keyboard.apk` из https://github.com/senzhk/ADBKeyBoard. После ввода восстанавливается предыдущая клавиатура. На Android 35 вспомогательный APK устанавливается с разрешением старого target SDK.

Если подключено несколько устройств, передайте серийный номер:

```powershell
$env:ANDROID_SERIAL = 'emulator-5554'
npm run screenshot -- catalog
```

Для установки APK используйте `android-sdk\platform-tools\adb.exe install <путь-к-apk>`. Для запуска приложения и навигации можно добавить сценарии с `adb shell monkey`, `am start` и `input`, либо подключить Appium, когда будет известен целевой APK и нужные пользовательские шаги.
